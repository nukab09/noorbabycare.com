# NOOR Baby Care

Cream-and-gold English website model for www.noorbabycare.com.
Tagline: For Little Ones, With Love.

## Included
Responsive storefront, category filters, search, variant selection, cart with local browser persistence, quantity controls, checkout details, delivery calculation, and a reviewable WhatsApp enquiry.

The catalog contains six SAMPLE listings with DEMO prices. It is not a full source-catalog import. No stock or real pricing is confirmed. WhatsApp opens a prefilled message; customers must send it. No order is submitted automatically, no customer information is saved to a server, and no online payment is processed. Only cart selections are stored locally.

## Review locally
Open index.html in a modern browser. No build tools, packages or server are needed.

## Edit products and images
Edit catalog.js. Prices are labelled as demo prices throughout this model.
See assets/README.md for original brand and product image filenames.
Use exact official logos; no substitute logo is included.

## Deploy with Netlify
1. Sign in to Netlify and select Add new project → Import an existing project.
2. Choose GitHub and grant Netlify access to nukab09/noorbabycare.com.
3. Select main. Leave the build command empty. Publish directory: .
4. Publish and review the Netlify URL. Repository updates can deploy automatically.
5. In Domain management → Production domains, add your existing domain.
6. Follow Netlify's domain instructions in Namecheap. Use the actual assigned site address and DNS targets rather than guessing values.

Do not enable GitHub Pages for this ecommerce storefront. GitHub hosts the source, Netlify hosts the site.

## Before real launch
- Replace sample products, options and demo prices with your own verified catalog.
- Add approved brand and exact product images.
- Verify phone, WhatsApp, email and address. Email in this model does not create an inbox.
- Confirm the rule for outside-Dhaka delivery charges (150 versus 200 taka).
- Add returns, refund, privacy and delivery policies.
- Implement server-side orders and payment integration with the chosen provider.
- Never add payment secret keys to this repository or browser JavaScript.
- Remove the model labels only after implementing the corresponding real behavior.
- Remove the noindex meta tag and update robots.txt when ready for search engines.
